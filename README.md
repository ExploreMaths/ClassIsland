> [!NOTE]
> 1. 请使用以下命令来复制此项目到电脑C盘：
>    
>    ```bash
>    cd /d C:\
>    git clone https://github.com/ExploreMaths/ClassIsland.git
>    ```
>    
> 2. 点击根目录<img height="24" alt="ClassIsland.exe" src="https://github.com/user-attachments/assets/e36de1c4-c899-469e-9fdc-45d107c64270" align="top"/>文件，按下<kbd>Alt</kbd>+<kbd>Enter</kbd>进入“属性”→“兼容性”，勾选“以管理员身份运行此程序”。
>    
> 3. 按下<kbd>Win</kbd>+<kbd>R</kbd>打开运行窗口，输入以下命令打开“启动”文件夹：
>    ```bash
>    shell:startup
>    ```
>    将根目录的<img height="24" alt="StartClassIsland" src="https://github.com/user-attachments/assets/d5eac047-3170-40db-88a1-905e2a763df3" align="top"/>快捷方式<ins>**复制**</ins>到“启动”文件夹中。
>
> 4. 启动后如发现字体缺失，请打开根目录<img height="24" alt="STZHONGS.TTF" src="https://github.com/user-attachments/assets/862fe9e3-dc43-489e-a3c7-d40aea1517d3" align="top"/>字体文件进行安装，完成后重启软件即可。
